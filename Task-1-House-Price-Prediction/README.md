# Task 1 - House Price Prediction

## Objective

The objective of this project is to predict house prices using Machine Learning.

## Algorithm Used

Linear Regression

## Features Used

- Living Area (GrLivArea)
- Number of Bedrooms (BedroomAbvGr)
- Number of Bathrooms (FullBath)

## Target Variable

- SalePrice

## Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Feature Selection
5. Train-Test Split
6. Linear Regression Model
7. Model Training
8. Prediction
9. Model Evaluation
10. Data Visualization

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
